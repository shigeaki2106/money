# YouTube 顔出しなし・声ありチャンネル 立ち上げガイド

条件: **顔出しNG / 声出しOK**

---

## 1. チャンネルの型(顔なし・声ありで成立する形式)

| 型 | 画面に映すもの | 向いている内容 |
|---|---|---|
| 画面録画+解説 | PC画面・チャート・スライド | 投資、プログラミング、ソフト解説 |
| ゲーム実況 | ゲーム画面 | 実況、攻略 |
| アバター(VTuber風) | 2D/3Dアバターが声に合わせて動く | 雑談、ライブ配信 |
| 手元・物撮り | 手元、作業風景、商品 | 料理、DIY、レビュー、勉強 |
| ラジオ・朗読 | 静止画+字幕や音声波形 | 雑談、朗読、解説 |

### このリポジトリと相性の良い企画
既にスイングトレード手法のバックテスト(`reports/`)があるので、そのまま「画面録画+解説」型の投資チャンネルの素材になります。

- 「日経225で5つの手法を20年分検証してみた」 → `reports/figures/equity_etf.png`, `equity_stocks.png`
- 「元手◯万円で月◯万円は届く?モンテカルロで確率計算」 → `reports/figures/mc_probability.png`
- 「バックテストの過剰最適化に注意」 → `reports/figures/overfit_check.png`
- Python コードを画面に映しながら「自分で検証する方法」シリーズ

> 注意: 投資系は「利益を保証する」「必ず儲かる」と取れる表現を避け、
> 動画冒頭と概要欄に「投資助言ではありません/過去の成績は将来を保証しません」と明記してください。
> 特定銘柄の売買推奨を有料で行うと金融商品取引法の投資助言業に当たる可能性があります。

## 2. 必要な機材・ソフト(最小構成)

| 用途 | おすすめ | 予算目安 |
|---|---|---|
| マイク | USBマイク(例: FIFINE K669、Audio-Technica AT2020USB+、Shure MV7+) | 3,000〜40,000円 |
| 録画・ライブ配信 | **OBS Studio**(無料) | 0円 |
| 動画編集 | DaVinci Resolve(無料)/ CapCut / Premiere Pro | 0円〜 |
| ノイズ除去 | OBSのフィルタ「ノイズ抑制(RNNoise)」、Audacity | 0円 |
| 字幕 | YouTube自動字幕の修正、Vrew | 0円〜 |
| サムネイル | Canva | 0円〜 |
| アバター(使う場合) | VTube Studio / Animaze / VRoid Studio | 0円〜 |

**最優先はマイク**です。顔を出さない分、音質がそのまま動画の印象になります。
ポップガード(数百円)と、声が響かない部屋(カーテン・布団のある部屋)で録るだけでも大きく変わります。

---

## 3. OBS の基本設定

1. **ソース**: 「画面キャプチャ」または「ウィンドウキャプチャ」+「音声入力キャプチャ(マイク)」
   - Webカメラのソースは追加しない(誤って顔が映る事故を防ぐ)
2. **マイクのフィルタ**: ノイズ抑制 → ノイズゲート → コンプレッサー → リミッター(-1dB)
3. **出力(録画)**: 1920×1080 / 30 or 60fps / 形式 mkv(録画後に mp4 へ再多重化)
4. **ライブ配信**: YouTube Studio →「ライブ配信を開始」→ ストリームキーを OBS の「配信」設定に貼り付け
   - ビットレート目安: 1080p30 で 6,000〜8,000 kbps
   - 初回のライブ配信は、アカウント確認後 **有効化まで最大24時間** かかることがあります

## 4. 顔バレ・身バレ対策チェックリスト

- [ ] Webカメラは物理的に外す/カバーする
- [ ] 画面録画時に通知・ブラウザのタブ・ブックマーク・ファイル名に本名や住所が出ないか
- [ ] デスクトップ背景・PCのユーザー名(`C:\Users\本名` 等)が映らないか
- [ ] 手元撮影時: 指輪・特徴的なほくろ・窓の外の景色・郵便物が映らないか
- [ ] 背景音: 地域の防災放送、近所の学校のチャイムなどで場所が特定されないか
- [ ] 画像のExif(位置情報)を消してからアップロード
- [ ] チャンネル用に **本名と紐づかない Google アカウント(ブランドアカウント)** を作成
- [ ] 収益化時の住所・本名は YouTube/AdSense 側のみで公開されない(視聴者には出ない)

---

## 5. 始める手順

1. Google アカウント(またはブランドアカウント)で YouTube チャンネル作成
2. チャンネル名・アイコン(イラストやロゴ)・バナーを作成
3. 電話番号で本人確認(15分超の動画、カスタムサムネ、ライブ配信が解放)
4. OBS で試し録り → 自分の声を聞いて音量・ノイズを調整
5. 最初の3〜5本を作ってから公開開始(投稿ペースを保てるように)
6. 週1〜2本の定期投稿+Shorts(縦型60秒以内)で認知を広げる

---

## 6. 収益化の条件(YouTube パートナープログラム)

- 広告収益: **登録者1,000人** かつ(過去12か月の総再生 **4,000時間** または 過去90日の Shorts 再生 **1,000万回**)
- 早期段階(メンバーシップ・スーパーチャット等): 登録者500人+一定の投稿・再生条件

> 数値は変更されることがあるので、YouTube 公式ヘルプで最新条件を確認してください。

### 顔なしチャンネルで気をつける規約
- **「再利用されたコンテンツ」** 扱いで収益化が通らないケースがあります。
  他人の動画・画像の切り貼りや、AI音声で読み上げるだけの量産動画は避け、
  **自分の声での解説・独自の分析(例: 自作バックテスト)** を入れると安全です。
- BGM・効果音は YouTube オーディオライブラリなど著作権的に使えるものだけを使う。
- AIで生成したリアルな映像・音声を使う場合は、アップロード時の「改変・合成コンテンツ」申告が必要です。
